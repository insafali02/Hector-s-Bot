What is Network Intelligence?+

A Discord bot for Minecraft Java server status, SRV/DNS details, public IP intelligence, subdomain discovery, protection signals and other network diagnostics.

How do I add the bot to my Discord server?+

Click “Add to Discord” and choose a server you have permission to manage. Use the Guild Install flow with the bot and applications.commands scopes so it joins as a normal server member.

Why is the bot missing from the member list or roles?+

It may have been installed as a User App instead of a Guild App, or its hosting process may not be connected. Revisit the Developer Portal installation settings and install using Guild Install.

What commands does the bot include?+

Minecraft: /mcserver, /status. Network: /ip, /asn, /whois, /dns, /domain, /subdomains, /protection, /cfbypass, /ping, /port, /route, /reverse, /subnet. Utilities and admin: /help, /invite, /setup, /servers, /synccommands, /block, /unblock, /blocklist.

Why are some slash commands not appearing?+

The bot’s commands are registered globally in the referenced v8 version. Check whether the bot is online, whether it was installed with applications.commands, and whether Server Settings → Integrations limits command visibility. The bot owner can use /synccommands to refresh or clear legacy guild-only commands.

Can I restrict sensitive commands?+

Yes. Owner commands such as /block, /unblock, /blocklist, /servers and /synccommands are restricted to configured owner IDs. /port and /cfbypass are administrator-only by default in the referenced configuration.

Does /mcserver reveal the real hidden backend IP?+

Not necessarily. It reports public DNS/SRV endpoints, IP:port candidates and provider metadata. A protected server may route traffic through TCPShield, another proxy or a CDN. Public results are not proof of a private origin.

How accurate are the country, city, ISP and ASN fields?+

The bot uses public metadata providers. ASN and network ownership may be reliable for registered ranges, but IP geolocation is approximate and can describe a proxy rather than the actual game host.

Does it work with Bedrock servers?+

The current /status and /mcserver handshake focuses on Minecraft Java Edition. Bedrock-only servers may show no Java status response.

Can I block an IP, subnet or domain from lookups?+

The configured bot owner can use /block, /unblock and /blocklist. Blocks apply globally, and the referenced implementation saves its blocklist in the bot host’s .env file.

Can I scan any IP or domain?+

The tool can perform bounded active diagnostics against public targets, but you must have authorization to test them. Restrictions, cooldowns and configured scan limits also apply.

Is this a DDoS or stress-attack bot?+

No. The supplied Network Intelligence bot does not include DDoS launch functionality. Its commands are for public information and scoped diagnostics.

Does the website track visitors?+

The provided website includes no analytics, tracking cookies, forms or accounts. Your hosting provider may still process normal request logs. See the Privacy Policy.

What data does the Discord bot use?+

It processes Discord interaction metadata and the domains, IPs or ports you submit for commands. It may request public data from external providers and log operational errors. See the Privacy Policy for details.

Where can I get help or report an issue?+

Use the Discord community button when the project owner has configured the support invite, or contact the operator using the address on the Terms and Privacy pages.
