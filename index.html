// TOOLKIT

Everything you need.
Nothing you don't.

Turn complex public network data into focused Discord reports. Built for developers, server admins, and curious communities.

Minecraft Intelligence

Live Java status, version, players, MOTD, SRV routing and public IP:port metadata.

/mcserver · /status

IP & ASN Research

Geolocation, network owner, reverse DNS, public registration data and routing context.

/ip · /asn · /whois

DNS & Subdomains

Explore A, AAAA, MX, TXT, SRV records, certificate-listed hostnames and DNS validation.

/dns · /domain · /subdomains

Protection Signals

Identify common CDN, edge, proxy and WAF hints from public metadata; never a guaranteed origin reveal.

/protection · /cfbypass

Network Diagnostics

Scoped ping, trace routes, TCP port checks, subnet calculations and PTR record lookups.

/ping · /route · /port

Owner Controls

Bot owner blocklists, installation diagnostics and private installed-server listings.

/block · /servers · /stats

Live Server Monitoring

Watch Minecraft availability, players and latency from a regularly updated Discord panel.

/livecheck · /stats · /servers
